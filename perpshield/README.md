# 🛡️ PerpShield — Pacifica Hackathon Project

PerpShield is a DeFi yield vault that generates passive income using delta-neutral strategies on perpetual futures.

## 🚀 Features (MVP)

* Deposit USDC into a vault
* Automated delta-neutral position (long + short)
* Yield generation via funding rates (simulated)
* Harvest function with bounty reward
* Rebalance mechanism with incentives

## 🛠️ Tech Stack

* Solidity (Smart Contracts)
* Hardhat (Development & Testing)
* OpenZeppelin (Security & Standards)
* Ethers.js (Interaction)

## 📦 Contracts

* `PerpShieldVault.sol` — Core vault logic
* `MockUSDC.sol` — Test token for local development

## 🧪 Scripts

* Deploy contracts
* Deposit / Withdraw testing
* Harvest & Rebalance simulation

## ⚠️ Note

This is an MVP built during the Pacifica Hackathon.
More features like ShieldScore, frontend UI, and Pacifica integration are in progress.
